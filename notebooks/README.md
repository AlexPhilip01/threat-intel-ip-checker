# notebooks/

Put your original `Threat_Intelligence_IP_Checker.ipynb` here if you'd like
to keep it around as a demo/exploration notebook.

It isn't included in this package — this environment can't read its
contents (GitHub blocks automated reads of raw notebook content) — and the
live dashboard app and CLI don't depend on it at all. `checker/engine.py`
is now the single source of truth for the actual checking logic.
